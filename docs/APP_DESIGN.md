# 만광 (만남의 광장) — 앱 설계 문서

3명이 돌아가며 쓰는 교환일기 웹앱. 디지털이지만 실제 일기장의 물성과 감성을 느끼게 하는 것이 핵심.

---

## 1. 화면 구성

### 1-1. 홈 — 세션 목록 (`/`)

로그인 후 가장 먼저 보는 화면.

**구성 요소:**
- 상단 헤더: 앱 이름 "만광", 프로필 아이콘
- 세션 카드 목록 (2개 섹션)
  - **진행 중인 일기**: 일기 제목, 참여자 3명 아바타, "내 차례" 뱃지, 마지막 작성일, 총 페이지 수
  - **완성된 일기**: 책 표지 형태의 썸네일
- 하단 플로팅 버튼: "새 일기 시작하기"

**디자인:**
- 세션 카드는 종이 질감, 약간 기울어지거나 겹쳐진 느낌
- "내 차례" 뱃지는 빨간 리본 느낌의 태그

---

### 1-2. 새 세션 만들기 (`/diary/new`)

**구성 요소:**
- 일기장 제목 입력
- 표지 테마 선택 (5가지: 봄꽃, 밤하늘, 크라프트지, 바다, 복숭아)
- 참여자 초대 (초대 링크 생성 — 최대 2명 추가로 총 3명)
- 종료 조건 설정 (페이지 수 / 라운드 수 / 수동 종료)
- "일기장 만들기" 버튼

---

### 1-3. 세션 상세 — 일기장 보기 (`/diary/[sessionId]`)

지금까지 작성된 모든 페이지를 책처럼 넘기며 보는 화면.

**구성 요소:**
- 상단: 일기장 제목, 참여자 목록, 세션 상태
- 중앙: 일기 페이지 뷰어 — **책 넘기기 형태**
  - 좌우 스와이프 또는 버튼으로 넘기기
  - 각 페이지: 작성자 이름, 작성일, 텍스트, 그림
  - 종이 질감 배경
- 하단:
  - 내 차례 → "일기 쓰기" 버튼
  - 내 차례 아님 → "OOO님이 쓰는 중..."
  - 완성됨 → "PDF로 내보내기" 버튼

---

### 1-4. 일기 작성 에디터 (`/editor/[sessionId]`)

**구성 요소:**
- 상단: 날짜(자동), 작성자 이름, "저장" / "취소"
- 본문 (고정 크기, 스크롤 없음):
  - **텍스트 영역**: 줄 노트 위에 손글씨 폰트
  - **그림 영역**: Fabric.js 캔버스 (텍스트와 비율 조절 가능, 기본 50:50)
- 그리기 도구:
  - 펜 (굵기 3단계), 색상 팔레트 (8~12색), 지우개, 되돌리기/다시하기
- 작성 완료 시: **"작성권 넘기기" 모달**
  - 나머지 2명 중 1명 선택
  - 한 줄 메시지 (선택, 예: "이어서 써줘!")
  - "넘기기" 버튼

---

### 1-5. 완성된 일기장 뷰어 (`/diary/[sessionId]/book`)

**구성 요소:**
- 표지: 제목, 참여자 3명, 기간
- 페이지 넘기기 애니메이션 (책 넘기는 느낌)
- 마지막 페이지: "이 일기는 OOO, OOO, OOO이 함께 썼습니다"
- PDF 내보내기 버튼

---

### 1-6. 로그인 (`/login`)

- 앱 로고 + 소개 문구
- "Google로 시작하기" 버튼

### 1-7. 프로필/설정 (모달)

- 닉네임 변경, 알림 설정, 로그아웃

---

## 2. 사용자 흐름

```
[로그인] → [홈: 세션 목록]
                │
        ┌───────┴────────┐
        v                v
  [새 세션 만들기]   [기존 세션 선택]
        │                │
        v                v
  [초대 링크 공유]   [세션 상세 보기]
        │                │
        v                ├── 내 차례 → [일기 작성 에디터]
  [3명 모이면             │                    │
   세션 시작]             │                    v
        │                │           [작성 완료 → 작성권 넘기기]
        v                │                    │
  [세션 상세 보기] ←──────┘                    v
                                    [다음 사람에게 알림]
                                             │
                                    (반복... 종료 조건 충족 시)
                                             │
                                    [세션 완성 → 완성 일기장 뷰어]
                                             │
                                    [PDF 내보내기]
```

## 3. 데이터 모델

### Session (일기장 한 권)

```typescript
type Session = {
  id: string
  title: string              // "우리의 여름 일기"
  theme: DiaryTheme          // "spring" | "night" | "kraft" | "ocean" | "peach"
  status: SessionStatus      // "waiting" | "active" | "completed"
  createdBy: string          // 생성자 userId
  members: string[]          // 참여자 3명
  currentWriter: string      // 현재 작성권 보유자
  closingRule: ClosingRule   // 종료 조건
  inviteCode: string         // 초대 코드
  createdAt: string
  completedAt: string | null
}
```

### Entry (일기 한 페이지)

```typescript
type Entry = {
  id: string
  sessionId: string
  authorId: string           // 작성자
  pageNumber: number         // 1부터 순차
  textContent: string        // 텍스트
  drawingData: string        // Fabric.js 캔버스 JSON
  drawingImageUrl: string    // 렌더링된 그림 이미지 URL
  passedTo: string           // 작성권 넘긴 대상
  passMessage: string | null // "이어서 써줘!"
  createdAt: string
}
```

### User

```typescript
type User = {
  id: string
  email: string
  displayName: string
  avatarUrl: string
  createdAt: string
}
```

### ClosingRule (종료 조건)

```typescript
type ClosingRule =
  | { type: "pageCount"; totalPages: number }   // 총 페이지 수 (예: 30)
  | { type: "roundCount"; totalRounds: number } // 라운드 수 (1라운드 = 3명 각 1번 = 3페이지)
  | { type: "manual" }                          // 수동 종료 (과반수 동의)
```

> **종료 조건 추천:** "시간 제한"은 제외. 교환일기의 본질은 "쓸 때까지 기다리는 여유"에 있고, 시간 압박은 이 감성에 맞지 않음. 대신 "내 차례가 된 지 N일 경과" 시 부드러운 리마인더 알림 정도면 충분.

## 4. 세션 생명주기

```
[생성] → [대기(waiting)] → [활성(active)] → [완성(completed)]
```

1. **생성**: 사용자 A가 제목, 테마, 종료 조건 설정. 초대 코드 생성.
2. **대기**: A가 초대 링크를 B, C에게 공유. 3명이 모이면 자동으로 활성화.
3. **활성**: 핵심 루프 — 작성 → 저장 → 작성권 넘기기 → 반복. 종료 조건 충족 시 완성.
4. **완성**: 수정 불가. 열람 + PDF 내보내기만 가능.

## 5. 핵심 인터랙션

### 작성권 넘기기

앱의 가장 핵심적인 인터랙션. 교환일기를 "건네주는" 감성을 살려야 함.

1. 작성 완료 버튼 클릭
2. 모달: 일기장을 건네는 일러스트
3. 2명의 참여자 카드 (아바타 + 닉네임)
4. 한 명 선택
5. 한 줄 메시지 작성 (선택)
6. "넘기기" → 일기장이 날아가는 애니메이션
7. 받는 사람에게 알림

### 페이지 열람

- 페이지 넘기기 (3D transform 종이 효과)
- 모바일: 스와이프 / 데스크톱: 화살표
- 작성자 아이콘 + 날짜 (오른쪽 하단)
- 넘길 때 남긴 메시지가 페이지 사이에 쪽지처럼 표시

## 6. 디자인 감성 — "물성"을 위한 요소

### 시각
- 종이 질감 배경 (테마별로 다름)
- 줄 노트 라인
- 페이지 모서리 접힘 효과 (dog-ear)
- 파스텔/자연색 팔레트
- 한글 손글씨 폰트 + 영문 serif 조합

### 인터랙션
- 페이지 넘기기 애니메이션
- 작성권 넘기기 모션
- 잉크 번지는 듯한 로딩
- 미세한 그림자로 깊이감

### 정서
- 넘길 때 한 줄 메시지 (쪽지 느낌)
- 완성 시 축하 화면
- 작성자별 고유 색상 라벨

## 8. 구현 우선순위

### 1단계 — 핵심 루프 (mock 데이터)
1. 데이터 타입 정의 + mock 데이터
2. 홈 화면 (세션 카드 목록)
3. 세션 상세 (페이지 열람)
4. 일기 작성 에디터 (텍스트 + 그리기)
5. 작성권 넘기기

### 2단계 — 완성 경험
6. 세션 종료 + 완성 일기장 뷰어
7. PDF 내보내기
8. 디자인 다듬기 (질감, 애니메이션)

### 3단계 — 멀티플레이어
9. Supabase 연동 (DB, 스토리지)
10. Google OAuth 로그인
11. 초대 링크 흐름
12. 실시간 알림
